# 🏗️ ПРОЄКТ 1: Transactional Order & Inventory API (Дні 1–5)

---

## 📌 День 1: TypeScript Utility Types, Docker (Postgres) та Основи NestJS

### Розклад (6 год)

- **Блок 1 (1 год):** Алгоритмічний розігрів — групування масиву подій користувачів через `.reduce()`, типізація через `Record` та `Partial`.
- **Блок 2 (1.5 год):** `docker-compose.yml` для PostgreSQL 16 та pgAdmin 4, кастомна мережа `order_network`, `healthcheck` через `pg_isready`.
- **Блок 3 (2.5 год):** Ініціалізація `order-service` на NestJS, модулі `Inventory` та `Orders`, реалізація Dependency Injection (DI) та Inversion of Control (IoC).
- **Блок 4 (1 год):** Питання для інтерв'ю: DI vs IoC, метадані рефлексії, різниця між `Record<K, T>` та index signature.

---

## 📌 День 2: Життєвий цикл запиту в NestJS (Pipes, Guards, Interceptors, Decorators)

### Розклад (6 год)

- **Блок 1 (1 год):** Алгоритмічний розігрів — побудова ієрархічного дерева категорій з плаского масиву (`Flat-to-Tree`) за $O(N)$.
- **Блок 2 (2 год):** Валідація DTO за допомогою `class-validator` і `ValidationPipe`, створення `RolesGuard` та кастомного метаданого декоратора `@Roles()`.
- **Блок 3 (2 год):** `LoggingInterceptor` для вимірювання часу виконання, `TransformInterceptor` для стандартизації структури відповідей API, Custom Param Decorator `@CurrentUser()`.
- **Блок 4 (1 год):** Питання для інтерв'ю: Порядок виконання Middleware -> Guard -> Interceptor -> Pipe -> Filter.

---

## 📌 День 3: Реляційні бази даних, SQL-зв'язки (1:1, 1:N, N:M) та ORM-міграції

### Розклад (6 год)

- **Блок 1 (1 год):** Алгоритмічний розігрів — Generic-функція `innerJoin` та `leftJoin` на TypeScript за лінійний час $O(N + M)$ за допомогою `Map`.
- **Блок 2 (2.5 год):** Проєктування схеми даних в ORM (Prisma/TypeORM): зв'язки `User` - `Profile` (1:1), `User` - `Order` (1:N), `Product` - `Category` (N:M).
- **Блок 3 (1.5 год):** Написання та накатка міграцій, Foreign Key constraints, каскадне видалення `ON DELETE CASCADE`, створення скрипту `seed.ts`.
- **Блок 4 (1 год):** Питання для інтерв'ю: Проблема N+1 в ORM, Eager vs Lazy Loading, збереження історичної ціни в `OrderItem`.

---

## 📌 День 4: Індексація в SQL, оптимізація запитів та EXPLAIN ANALYZE

### Розклад (6 год)

- **Блок 1 (1 год):** Алгоритмічний розігрів — клас `ProductIndex`: швидка фільтрація за категорією $O(1)$ та бінарний пошук діапазону цін $O(\log N)$.
- **Блок 2 (2.5 год):** Генерація 200,000+ тестових замовлень у PostgreSQL, аналіз повільних запитів через `EXPLAIN (ANALYZE, BUFFERS)`: `Seq Scan` vs `Index Scan`.
- **Блок 3 (1.5 год):** Складені індекси (Composite Indexes), перевірка правила лівого префікса (Leftmost Prefix Rule), часткові індекси (Partial Indexes).
- **Блок 4 (1 год):** Питання для інтерв'ю: Внутрішня будова B-Tree індексу, Bitmap Scan, ціна надмірної індексації при операціях запису.

---

## 📌 День 5: Транзакції в SQL, рівні ізоляції та блокування (Pessimistic vs Optimistic)

### Розклад (6 год)

- **Блок 1 (1 год):** Алгоритмічний розігрів — створення класу `Mutex` для взаємного виключення асинхронних операцій у Node.js.
- **Блок 2 (2.5 год):** Практичне відтворення аномалії `Lost Update` у двох паралельних сесіях PostgreSQL, тестування рівнів ізоляції `READ COMMITTED`, `REPEATABLE READ`, `SERIALIZABLE`.
- **Блок 3 (1.5 год):** Боротьба зі станом гонитви (race condition) при списанні залишків: реалізація Pessimistic Lock (`SELECT ... FOR UPDATE`) та Optimistic Lock (стовпчик `version`).
- **Блок 4 (1 год):** Підсумки Проєкту 1: ACID, взаємні блокування (Deadlocks) та стратегії їх уникнення.

## 📌 День 7: Складні багатоступеневі агрегації, джоїни ($lookup) та $facet

### Розклад (6 год)

- **Блок 1 (1 год):** Алгоритмічний розігрів — функція `unwind` на TypeScript: розгортання вкладеного масиву об'єктів у плаский список.
- **Блок 2 (2.5 год):** Реалізація реляційних джоїнів у MongoDB через `$lookup` (приєднання даних покупців і товарів до аналітики замовлень).
- **Блок 3 (1.5 год):** Використання оператора `$facet` для створення багатовимірного дашборду за один запит (загальний виторг + топ-5 товарів + розподіл за категоріями).
- **Блок 4 (1 год):** Питання для інтерв'ю: Складність та оптимізація `$lookup`, колізії схем, вкладені масиви та продуктивність `$unwind`.

### Розклад (6 год)
